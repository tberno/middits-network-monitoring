# middits-network-monitoring

Repo for Middlebury alerting work across Graylog, NMS, Mist, and the alert broker.

## Layout
- broker/ : Flask broker and shared formatting logic
- graylog/scripts/ : current Graylog-related scripts copied from raccoon
- nms/ : current NMS-related scripts copied from raccoon
- mist/ : Mist integration work
- archive/ : older helper scripts and one-off fixes preserved during migration
